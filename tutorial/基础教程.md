# 0.前置知识准备
1. axis axi4 axilite（可选）协议需要大致理解，请注意，axis协议是corundum的主要传输协议，务必掌握
2. 学习计算机组成原理对开发riscv部分是有帮助的，至少要知道riscv core的组成部分，如何去修改DTS，还有openocd的概念与使用：有时间可以看看一生一芯
3. 网络驱动开发基础请大致了解，理解网卡的5个队列：发送/接收 ，发送完成、接收完成，事件队列
4. 需要能看懂dpdk代码：请参考学长学姐的笔记
5. verilog的基本语法，基本激励文件编写
6. 对于应用层：根据自己的应用学习相关的知识，比如spark
# 0.1 快速开始
1. vivado中安装u280的板子文件：https://driver.bigstorm.top/f/3bs7/au280.rar（vpn下载）
2. 在zwz服务器的bupt用户下有创建好的工程，corundum是无rmt工程，corundum-withrmt-dev是app block中含有rmt的工程，请拷贝后自行打开，不要**原地修改**！
3. 如果想在zwz服务器上进行烧录，切记，**不要直接进行program**，
	1. 请在bupt/corunudm文件夹下执行```sudo ./script.sh 1```,再开始烧录
	2. 烧录完后，请执行```sudo ./script.sh 2```，恢复驱动及ip和arp表
	3. 原因请看corunudm文档的的debug章节


# 1. corundum
开始前，推荐阅读corundum论文：https://cseweb.ucsd.edu/~snoeren/papers/corundum-fccm20.pdf
以及corundum文档：https://docs.corundum.io/en/latest/ module部分介绍了硬件的数据通路
最初版携带riscv的工程请下载：https://github.com/likewise/corundum/tree/add-vexriscv-facet，注意，此版本为u50版本
1. 先跟着corundum文档启动corundum cocotb仿真，可以看到所有仿真数据
2. 我们的重点是app_block模块，请优先关注此模块周边模块，interface外的模块可以暂时不理会
# riscv
vexriscv：https://github.com/SpinalHDL/VexRiscv
本工程使用的riscv生成地址：https://github.com/likewise/Finka
1. python3 -m serial.tools.miniterm /dev/ttyUSB2 115200 可以看到串口输出
2. 编译riscv工具链：天坑，建议直接在github上根据版本用编译好的
2. 在工程的app的template中有openocd，可以跟着readme进行程序 gdb debug处理
# RMT
请先阅读论文：http://cjc.ict.ac.cn/online/onlinepaper/yxr-2024229165209.pdf
fast RMT工程地址：https://github.com/multitenancy-project/menshen 里面记录了如何将工程嵌入至corundum的u250版本
rmt_v2文件夹中是主要逻辑，还有仿真文件可以在vivado中进行仿真

# 分流器部分

# 从源头构建
1. 克隆本仓库后，进入path/to/repo/fpga/mqnic/AU280/fpga_100g
``` shell
make clean
make
```
如果报错，参照menshen设置一下环境变量
2. 执行到make syth命令时，手动退出，（如果不手动退出也会报错）
3. 打开vivado 添加源文件
	1. riscvparser：自己写的app模块中template/rtl下面的文件
	2. rmt_lib下面的两个ip核
4. 在vivado中完成综合和布局布线
